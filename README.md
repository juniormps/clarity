# Clarity

Aplicação full stack de gerenciamento de tarefas desenvolvida como projeto de estudo.

O objetivo do projeto é praticar a construção de uma aplicação completa, desde a interface até a persistência dos dados, utilizando uma arquitetura organizada e desenvolvimento incremental.

## Stack planejada

### Front-end

- React
- TypeScript
- Vite
- CSS Modules
- React Router DOM
- Redux Toolkit quando houver necessidade de estado global

### Back-end

- Node.js
- Express
- TypeScript

### Banco de dados

- MySQL
- mysql2/promise
- SQL puro, sem ORM

## Arquitetura

O projeto será organizado em três partes principais:

- `client/` — aplicação front-end;
- `server/` — API;
- `database/` — migrations e scripts relacionados ao banco de dados.

## Desenvolvimento

O projeto será desenvolvido incrementalmente, com pequenas funcionalidades e commits que representem etapas coerentes da evolução da aplicação.

As funcionalidades serão preferencialmente implementadas verticalmente:

Frontend → API → regras de negócio → persistência
